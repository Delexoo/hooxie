Help center

Start Hooxie

Run Hooxie on Windows. The pill sits at the top center. Choose the project folder before the first prompt.

Voice, screen, and files

An empty prompt shows the microphone. Text turns that button into send. While the agent is working, the same button is a square and stops the run. “View the screen” attaches a screenshot. The plus button adds files or a folder.

Hide from a call

Turn Detectable off, or start a session with Ctrl+Shift+\. You still see Hooxie. A normal screen share does not.
