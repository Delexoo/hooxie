Start

Run Hooxie on Windows. The pill sits at the top center. In Connections, pick the IDE and a project file or folder before the first prompt. Setup is two steps: the IDE, then the $5.99 license for this computer.

Take the short intro or read Help.

Ask

Type and press Enter, or use the send button. An empty prompt shows the microphone. While the agent is working, that button is a square and stops the run. View the screen attaches a screenshot. The plus button adds a file or a folder.

The full guide is in Documentation.

Stay off a screen share

Turn Detectable off in Settings, or press Ctrl+Shift+\. You still see the pill and this window. A normal screen share does not see either one.

Connections

Unlink all IDEs clears the editor Hooxie is using. Connections is one list. Connect opens that service’s key page in the browser when one exists. When that is not available, the list returns to normal and you paste under Advanced. You can keep more than one. Advanced also holds a negative prompt and memory presets.
