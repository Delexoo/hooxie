Features

Built to sit over Cursor, not inside it.

01

New agent sessions

Each send starts a Cursor agent on the project folder on the pill. It is not a paste into an already-open Composer thread.

02

Voice, then send

An empty prompt is a microphone. Words turn the same control into send. A stop square appears while the agent is working.

03

The screen, on purpose

“View the screen” attaches a screenshot. Ctrl+Enter asks about the current display even if that switch is off.

04

Files and folders

Drop files, add a folder, and keep them on the pill. Secrets such as .env and private keys are refused.

05

Live run detail

Terminals, queued follow-ups, and modified files show only when the run has them. Queue the next prompt with Enter while the agent works.

06

Your Cursor account

Connect Cursor in the widget. Sign-in opens in the browser. A pasted official SDK key also works.

Setup

What Hooxie needs

  1. Install Cursor. Get the desktop app from cursor.com and open it once.
  2. Sign in. Hooxie talks to the Cursor account on this computer.
  3. Keep a Cursor plan available. Hobby, Pro, Pro+, Ultra, or Business — and it has to be active. Hooxie Pro does not replace that plan.

Onboarding

Two chapters, then the widget.

  1. IDE. Turn on the IDE Hooxie should use. Off means that IDE is disconnected. Download is there if it is not installed yet.
  2. License. $5.99 once for this computer. The license stays on this device. A copied app does not unlock another one.
