The pill

Hooxie opens as a pill at the top center of the screen. The prompt stays on that bar. Add a file on the left. Send, or start voice, on the right. Presets, more, usage, the dashboard, and the drag handle sit beside it.

View the screen, the project path, attachments, and the conversation open when you type, attach a file, already have a conversation, are listening, or the agent is working. Clear the prompt and they fold away.

When a line is about to run out of room, those controls move under the field. More typing wraps, and the field grows downward. Drag the bottom of the conversation to make it taller.

Prompts

Type and press Enter, or use the send button. Set the project folder first. That folder is the workspace the agent uses. Each prompt starts a new session for that folder. It does not continue a chat you already have open in the IDE.

While the agent is working, the round button becomes a square and stops the run. A prompt you type during that run is queued. Queued messages are numbered cards. The first one sends next, and each card can be removed. The field says “Queue a follow-up” while one is in progress.

Under the conversation you can clear the chat, copy the reply, or send the last prompt again. Clear chat is also in More, and on Ctrl+R.

Presets

Open Presets, give the prompt a name, and save it. You can keep forty. Use current prompt copies whatever is in the field. Use puts a saved prompt back in the field so you can send it again. Delete removes one.

Files and the screen

The plus button adds files. Right-click it, or drop a folder, to attach a folder. Click a preview to read the file before you send. Close leaves the preview.

View the screen attaches a screenshot of the current display to the next prompt. Ctrl+Enter asks about the screen even when that switch is off. If you were dictating, the spoken text is the prompt.

When the session changes files, the widget lists them as added, modified, or deleted. A running terminal from that session shows its command.

In the dashboard, under IDE, you can add standing instructions, and list files inside the project, one relative path per line. Two switches can also put the project path, or stack markers found in the project root, into the prompt text.

Voice

With an empty prompt, the round button is the microphone. Click it to start, click again to stop. Words appear as you speak. When the field has text, that button is send.

Turn Voice activation on in the dashboard and say “Say Hooxie” or “Hey Hooxie.” The open sound means you can speak. A short pause sends the prompt. A long silence with no words ends the listen. Windows speech recognition has to be installed for this.

Choose the microphone and speaker in the dashboard, or turn voice prompting off there. The microphone uses the Windows communications device until you pick another.

Sounds

Three sounds belong to the widget. Opening plays when the typing outline appears. Closing plays when that outline turns off, including when you click out of the prompt or stop voice. Done plays when the agent finishes.

In the dashboard, each one is a waveform with its name and a play button. Pick a sound for each, turn one off, or upload your own. They play on the speaker you chose.

The typing outline is a light blue, blue, and purple line around the pill while you type or talk. Turn it off in General if you want the pill quiet. Hold Escape for three quarters of a second to clear the prompt and let the widget go. While you hold it, the outline color closes around the border.

Hide and move

Ctrl+\ slides the pill off the nearest edge and fades it out. Press it again, click the tray icon, or press Ctrl+Alt+H, and it glides back. Pressing the shortcut during the slide reverses it. More also has Hide Hooxie, and Recenter, which returns the pill to the top center.

Drag the dotted handle to place the pill. Move Hooxie in More follows the pointer until you click. Turn on Arrow keys in General, and Ctrl plus an arrow moves it up, down, left, or right. Until that switch is on, those shortcuts stay with your other apps.

Undetectable hides Hooxie from a normal screen share or recording. You still see it. Turn it on from More, from Detectable in the dashboard, or with Ctrl+Shift+\, which starts or stops a session.

Usage

The ring on the pill is the included usage for the connected Cursor account. While it is loading, the ring eases around the circle, then fills to the percentage. Open it for the plan, included amount, auto, API, bonus, credits, and when it resets.

That number is the agent account’s usage. The $5.99 Hooxie license does not replace that plan, and it does not add to it.

The project

Pick an IDE in setup or in the dashboard. The widget uses that one, and you can switch it. If it is not installed, that choice opens the download and stays off. The IDE list has the downloads. Setup is two steps: the IDE, then the license. The prompt stays hidden until an IDE is connected and this computer is licensed.

Hooxie is $5.99 once for this computer. Sharing the app or the license file does not unlock another computer. If this computer is already paid for, Hooxie finds that payment and continues.

The project path on the pill is the folder Hooxie may use. Browse to it, or pick a recent workspace. More can open that folder in the connected IDE. Change IDE in that same menu switches which IDE the widget uses.

How the prompt is delivered depends on the IDE:

  • Cursor agent. With Cursor connected, Hooxie sends the prompt to that agent. Sign in from the browser, or paste an API key. Allow the agent to run outside the sandbox only if you turn that on.
  • IDE chat input. The companion places the text in the IDE’s chat field. That placement is not the agent accepting the prompt, and agent progress stays unavailable. Ask the IDE to submit is experimental and not verified.
  • Clipboard. Hooxie copies the prompt. You paste it and submit it in the IDE.

A route that cannot carry images will say so. Take the screenshot off, or remove the picture, before you send.

Dashboard

The dashboard opens inside Hooxie. It is a white window with a grey sidebar. Dark is available, and the pill has its own light or dark look. White stays the primary color. Button color and background opacity are on General.

General holds the version, Detectable, the session, audio, the microphone, the speaker, voice activation, the typing outline, and arrow keys. IDE holds the connection, the project, the installation, the delivery route, instructions, and the file list. Keybinds lists the shortcuts. Language translates the dashboard. Billing is the one-time purchase for this computer, including a promotional code. Support links to these notes, Help, and contact.

Toggle Hooxie stays at the bottom of the sidebar and hides or shows the pill. Collapse the sidebar when you want only the icons.
