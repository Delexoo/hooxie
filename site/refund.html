Refund policy

Effective 12 October 2026.

The plan

Hooxie is $5.99 once for the computer that bought it. There is no renewal. A refund request does not, by itself, move that license to another device.

14 days

If the $5.99 charge was a mistake, email support@delexo.store within 14 days of that charge. Include the email on the Stripe receipt. We refund that charge. There is no renewal.

Promotional codes

A code that takes the price to $0 does not create a payment, so there is nothing to refund. If a code only reduces the price, the 14-day window applies to the amount Stripe actually charged.

How a refund is sent

Refunds go back through Stripe to the original payment method. Stripe's timing applies, often a few days and sometimes longer for the bank.
