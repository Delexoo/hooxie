v0.2.0 Latest 16 Oct 2026

Type fold, voice outline, and a license for this computer

Widget

  • The prompt stays on the bar, with upload on the left and send or voice on the right. Presets, more, usage, dashboard, and drag sit beside it.
  • View the screen, the project path, attachments, and the conversation open when you type, attach a file, already have a conversation, are listening, or the agent is working. Clearing the prompt folds them away.
  • When a line is about to run out of room, those controls move under the field. More typing wraps, and the field grows downward.
  • The widget opens a little lower on the screen. The scrollbar is only on the conversation.
  • More options can open the connected IDE on the current project.
  • More options includes Change IDE, which switches the IDE the widget uses.
  • Hooxie Setup 0.2.0 installs the app for Windows. The product site is hooxie.com.
  • While Cursor usage is loading, the ring eases around the circle, then fills to the percentage. That spin and fill take a little longer.
  • Ctrl+\ slides the pill off the nearest edge of the screen and fades it out. Showing it glides back. Pressing the shortcut again during the slide reverses it.
  • More options includes Recenter, which moves the pill back to the top center.
  • The app and installer icon is a sharper rounded pill.
  • The installer icon is a rounded squircle, so the setup file no longer shows a square tile.
  • Clear chat, Copy reply, and Send again have more padding, so the labels no longer sit on the rounded ends.

Dashboard

  • The search button and its search field are gone.
  • The website menu no longer opens a separate dashboard. The dashboard is the window inside Hooxie.
  • The window is white, with a grey sidebar and black text. Dark is still available.
  • Toggle Hooxie stays at the bottom of the sidebar.
  • Buttons and language choices are pills. A collapsed sidebar uses circles.
  • English, Spanish, French, German, Portuguese, Japanese, and Chinese translate the navigation, help, and the one-time $5.99 purchase. Switching back to English restores the original words.
  • Opening a section eases in, and collapsing the sidebar glides.
  • Opening the dashboard no longer stops on a missing catalog or revision.
  • The microphone and speaker lists stay open when you click them.
  • Opening, closing, and done each have a sound list, shown as a waveform with the name and a play preview.
  • Dashboard motion fades in, and buttons grow slightly on hover and click.
  • Dashboard pages sit in the center of the window.
  • The dashboard stays on its own pages. Help, notes, contact, and downloads no longer open another site in that window.

Setup

  • Setup is two steps: choose an IDE, then the license. Back and Next move between them, and a progress bar shows how far along you are.
  • Each IDE has a plain Download link and a switch. On means the widget uses that IDE. Only one IDE can be on. An IDE that is not installed stays off.
  • Setup can be dragged, minimized, and closed. Help opens the onboarding section of the website.
  • Hooxie is $5.99 once for this computer. Sharing the app or the license file does not unlock another computer.
  • If this computer is already paid for, Hooxie finds that payment and continues.

Voice

  • Saying “Hooxie” starts one voice session.
  • The open sound plays when the typing outline appears. The close sound plays when that outline turns off, including when you click out of the prompt or stop voice.
  • Holding Escape for three quarters of a second clears the prompt and lets the widget go. While you hold it, the outline color closes around the border. When the hold finishes, the outline stays closed.
  • The blue-to-peach outline travels around the widget.
  • Placeholder questions type on one letter at a time.

Chat

  • Conversation text is smaller and more compact.
  • Queued messages are numbered cards. The first one sends next, and each card can be removed.

Site

  • The footer spreads Download, Help, IDEs, Releases, Contact, and Legal under Product.
  • Documentation covers the widget: the pill, prompts, presets, voice, files, the screen, usage, and shortcuts.
  • The home title and the Download and Learn more control sit in the center of the screen.
  • The home title stays locked while the demo computer scrolls up over it.
  • On a phone, the demo computer fills the screen while the prompt types, and the caret stays in the field.
  • Clicking the demo prompt lets you type in it, and scrolling no longer replaces what you wrote.
v0.1.0 12 Oct 2026

First public build

First build

  • The widget sits at the top of the screen and sends a prompt to a Cursor agent for the folder you choose.
  • One button is the microphone when the prompt is empty, send when there is text, and a square stop while the agent is working.
  • You can attach files, a folder, or a screenshot of the current screen.
  • Detectable can be turned off so a normal screen share or recording does not show Hooxie.
  • Keybinds hide or show the widget, ask about the screen, clear the chat, start a session, and move the pill.
