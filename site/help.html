Help center

Before Hooxie can send

Hooxie needs the Cursor desktop app. Download Cursor, install it, and sign in. The account also needs an available Cursor plan: Hobby, Pro, Pro+, Ultra, or Business, and that plan has to be active. See Cursor plans. Hooxie Pro ($4.99/month) is a separate subscription and does not replace a Cursor plan.

The widget checks the install, the sign-in, and the plan before a prompt can be sent. If a step is still open, the pill lists it and tells you what to do. Use Download Cursor, Cursor plans, and Check again on that panel.

Press Connect Cursor on the pill or in the dashboard. Sign-in opens in the browser and links the account. A pasted API key also works if you already have one.

Open the widget

Start Hooxie on Windows. A pill appears at the top center. Set the project folder before you send. That folder is the agent's workspace.

Send a prompt

Type and press Enter, or use the send icon. Each prompt starts a new agent session for that folder. It does not continue an already-open Composer thread.

Voice

With an empty prompt, the round button is the microphone. Click it to start, click again to stop. When words are in the prompt, the button becomes send. Audio uses the Windows default microphone, and you can turn it off in the dashboard.

Screen

The “View the screen” switch attaches a screenshot to the next prompt. Ctrl+Enter asks about the current screen even if that switch is off. If you were dictating, the spoken text is the prompt.

Files

The plus button adds files. Right-click it to add a folder. Click a preview to check the file before you send.

Calls and recordings

Turn Detectable off in the dashboard, or press Ctrl+Shift+\. You still see the widget. Standard screen capture does not.

Move and hide

Turn on Arrow keys in the dashboard, then Ctrl plus an arrow moves the pill. Until then those shortcuts stay with your other apps. Ctrl+\ hides Hooxie and shows it again. The tray icon and Ctrl+Alt+H also bring it back.

Billing

Pro is $4.99 a month. Subscribe from the dashboard. A promotional code goes in the field on that page. Refunds are described on the refund page.
