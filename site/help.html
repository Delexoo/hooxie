Help center

The full guide to the widget is in Documentation. This page is the short version for setup.

IDE

Pick an IDE from the list. The widget uses that IDE, and you can switch it any time. If it is not on this computer, that choice opens its download and stays off until it is installed.

License

Hooxie is $5.99 once for this computer. The license belongs to this device. Sharing the app, or copying its license file, does not unlock another computer. Purchase opens checkout in the browser. The widget unlocks when payment for this computer is confirmed.

Move through setup

Help in the widget opens this section. Drag the top bar to move setup. Minimize collapses it to that bar. Close hides Hooxie, and Ctrl+\ shows it again. The prompt, voice, and the rest of the widget stay hidden until an IDE is on and this computer is licensed.

Before Hooxie can send

Hooxie needs an IDE on this computer. Download an IDE if none is installed, then choose it in the list. The agent also needs a sign-in. The rest of the widget stays hidden until that IDE is connected and this computer is licensed.

Sign in to the agent and keep its plan active. The $5.99 Hooxie license does not replace that plan.

Press connect on the pill or in the dashboard. Sign-in opens in the browser and links the account. A pasted API key also works if you already have one.

Open the widget

Start Hooxie on Windows. A pill appears at the top center. Set the project folder before you send. That folder is the agent's workspace.

Send a prompt

Type and press Enter, or use the send icon. Each prompt starts a new agent session for that folder. It does not continue an already-open chat thread.

Voice

With an empty prompt, the round button is the microphone. Click it to start, click again to stop. Words appear as you speak, and a short pause keeps the phrase. When words are in the prompt, the button becomes send. Choose the microphone and speaker in the dashboard, or turn voice prompting off there.

Screen

The “View the screen” switch attaches a screenshot to the next prompt. Ctrl+Enter asks about the current screen even if that switch is off. If you were dictating, the spoken text is the prompt.

Files

The plus button adds files. Right-click it to add a folder. Click a preview to check the file before you send.

Calls and recordings

Turn Detectable off in the dashboard, or press Ctrl+Shift+\. You still see the widget. Standard screen capture does not.

Move and hide

Turn on Arrow keys in the dashboard, then Ctrl plus an arrow moves the pill. Until then those shortcuts stay with your other apps. Ctrl+\ hides Hooxie and shows it again. The tray icon and Ctrl+Alt+H also bring it back.

Billing

Hooxie is $5.99 once for this computer. Buy it from the License chapter in setup, or from the dashboard. A promotional code goes in the field on that page. Refunds are described on the refund page.
